# 光魔增长 · 现代 B 端办公设计规范（Design System）

> 本文档是 `apps/web` 的前置视觉与交互契约。人工开发与 AI Agent 新增或修改页面时，必须遵守本规范，避免回退到默认模板化的“AI 展示页风格”。

## 1. 风格定位

本产品是**团队内部高频使用的增长情报与协作办公台**，采用**现代 B 端办公风**（对标飞书工作台 / Arco Design 信息密度与中文阅读体验）：

- **清晰分层**：冷浅灰画布（`#F5F6F7`）承托纯白工作区表面（`#FFFFFF`），用 `1px` 细边框（`#DEE0E3`）而非重阴影建立层级。
- **克制主色**：主交互色为办公蓝（`#3370FF`），用于主按钮、导航激活态、当前标签页、文字链接和聚焦框；大面积仍保持中性白与浅灰。
- **语义分明**：所有业务状态（待确认、已确认、进行中、失败、高优等）必须通过语义色标签区分，不能全部使用同一种黑白描边标签。
- **效率优先**：信息密度适中偏高，首屏直接展示筛选器、核心数据表或待办列表，减少装饰性留白和宣传性文案。

## 2. 色彩与语义 Token

所有颜色定义在 `apps/web/src/styles/globals.css`，禁止在业务组件中散写任意 HEX 颜色（除数据可视化外）。

| 语义                   | 浅色基准              | 用途                                       |
| ---------------------- | --------------------- | ------------------------------------------ |
| `--background`         | `#F5F6F7`             | 页面画布底色                               |
| `--card` / `--popover` | `#FFFFFF`             | 表格容器、列表面板、表单卡片、弹窗         |
| `--sidebar`            | `#FFFFFF`             | 左侧导航栏表面                             |
| `--primary`            | `#3370FF`             | 主按钮、激活导航文字、主要链接、Tab 下划线 |
| `--primary-soft`       | `#EDF3FF`             | 导航选中底色、轻高亮背景                   |
| `--foreground`         | `#1F2329`             | 正文、标题、表内主字段                     |
| `--muted-foreground`   | `#646A73`             | 次级说明、时间戳、表头、辅助文字           |
| `--border`             | `#DEE0E3`             | 容器与表格分割线                           |
| `--status-info-*`      | `#EDF3FF` / `#245BDB` | 运行中、研究中、待确认、进行中             |
| `--status-success-*`   | `#E8F7EE` / `#0F7B43` | 已确认、已完成、正常启用                   |
| `--status-warning-*`   | `#FFF4E5` / `#B45309` | 待审核、待补证、暂停、待处理               |
| `--status-danger-*`    | `#FEECEE` / `#C92A2A` | 失败、拒绝、高优先级、已停用               |
| `--status-neutral-*`   | `#F0F1F4` / `#525866` | 不相关、已取消、低优先级、未分配           |

## 3. 排版、尺寸与圆角

- **字体**：`Inter, -apple-system, BlinkMacSystemFont, 'PingFang SC', 'Hiragino Sans GB', 'Microsoft YaHei', sans-serif`。
- **数字对齐**：统计数字、评分、日期时间、计数统一加 `tabular-nums`。
- **字号阶梯**：
  - 页面标题：`text-lg font-semibold`（18px），单行紧凑，避免超大 `text-2xl` / `text-3xl`。
  - 模块标题：`text-sm font-semibold`（14px）。
  - 表格与表单正文：`text-[13px]`（13px）或 `text-sm`（14px）。
  - 辅助信息/表头/标签：`text-xs`（12px）。
- **控件高度**：
  - 标准按钮、输入框、下拉框：`h-8`（32px）。
  - 紧凑工具栏/表格行内操作：`h-7`（28px，`size="sm"`）。
  - 独立登录表单主按钮等极少数场景可用 `h-9`（36px，`size="lg"`）。
- **圆角**：基础圆角 `6px`（`rounded-md`），面板/弹窗 `8px`（`rounded-lg`），标签 `4px`（`rounded`）。

## 4. 页面骨架规范

1. **顶部工作栏**：
   - 全局顶栏固定 `h-12`（48px），仅显示面包屑/当前页面标题、主题切换和必要的当前状态，不放无业务作用的装饰胶囊。
   - 产品上下文栏紧贴内容顶部，紧凑单行展示当前产品切换。
2. **侧栏分组**：按高频工作流分为三组（工作台 / 情报与监测 / 研究与系统），每项使用唯一语义图标，选中态用浅蓝底 + 蓝字。
3. **列表页标准结构**：
   - 紧凑 `PageHeading`（标题 + 一句说明 + 右侧主操作组）
   - 状态/视图 Tab 栏（底部细横线 + 蓝色下划线激活态，不用按钮堆砌）
   - 统一白底 `FilterBar`（筛选下拉 + 搜索框 + 清除按钮）
   - 白底圆角边框 `Table` 容器（浅灰表头 `bg-muted/60` + 清晰行分割 + 底部条数栏）
4. **详情与编辑**：优先使用结构清晰的弹窗/抽屉，信息分块（基础元信息条 → 正文/摘要 → 证据与关联任务 → 底部固定语义操作区）。

## 5. 明确禁止的“AI 味”反模式

新增或重构任何页面时，禁止出现以下模式：

- **禁止**无业务动作的“4 格超大 KPI 数字卡 + 居中大图标”堆满首屏；概览统计应使用紧凑指标条并直接链接到对应处理队列。
- **禁止**营销式二分屏登录页、全大写英文装饰口号（如 `WORKSPACE` 标语）、渐变炫光或无意义状态绿点胶囊。
- **禁止**巨大的居中虚线框空状态（`min-h-64 border-dashed`）；统一使用 `EmptyState` 紧凑白底卡片。
- **禁止**将高频列表（如情报、任务）做成满宽大圆角留白卡片堆叠；优先使用紧凑表格或结构化条目列表。
- **禁止**全部状态标签使用同一无色 `Badge variant="outline"`；必须映射到 `Badge` 的 `info` / `success` / `warning` / `danger` / `neutral` 语义变体。

## 6. UI 改动验收标准（后置走查清单）

每次涉及前端界面的变更，提交前必须核对：

1. 桌面端（1440×900）首屏能否直接看到核心操作区与真实数据行，无多余空洞留白。
2. 移动端（390×844）抽屉导航、筛选器折行、表格横向滚动正常，无横向溢出。
3. 加载态、空状态、错误态、无权限/只读态、深色模式均保持一致的对比度与语义色。
4. 通过 `pnpm verify:ui`（或手动截屏）保留变更页面截图作为审阅证据。
