# 产品与成员授权

产品是贯穿概览、研究、候选、情报、计划和任务的业务归属。产品目录支持新增、编辑简介/显示名称、归档和恢复；固定产品标识关联历史数据，不能通过改名迁移归属。MagicTattoo、MagicLight 已迁移为数据库记录，新增产品无需修改代码。

角色决定操作权限：管理员管理产品与成员授权，运营执行业务操作，只读成员只能读取。管理员访问全部产品，其他成员必须有 product_members 授权；新成员默认无产品，新增产品默认不向普通成员开放。当前是团队级角色加产品访问集合，尚非每个产品单独配置角色。

所有列表、统计、详情、研究 SSE、候选审核、评分、任务及计划写入都在服务端检查归属。选择“全部授权产品”仅聚合授权范围；自行修改 URL 不能扩大范围。负责人还需有对应产品权限。ProductAccess 共享授权谓词，Worker 使用数据库 canAccessProduct 复查，模型输出不能决定权限或更改产品。研究和提取在执行前及保存前检查权限；已发出的外部模型调用无法因撤权即时取消，结果不会继续正常提交。尚无强制取消机制。

顶部统一产品选择保存于 URL 与当前标签页的成员偏好。各产品使用独立查询缓存，切换后清理旧缓存。目录每 10 秒刷新，成员授权撤销后 API 下一次访问立即拒绝，浏览器在目录刷新后清理已缓存范围；已展示或下载的数据无法撤回。产品名称用于显示，标识用于关联。新研究/定时计划必须指定产品；候选继承研究产品，任务继承情报产品，已归属记录不允许跨产品修改。

迁移 0006 先建立产品目录并从已有情报/任务/候选提取标识，再增加外键。为保留既有共享工作方式，仅给迁移时已有非管理员授予原两产品访问权；后续产品和成员都需明确授权。历史研究只有所有已有候选一致时自动归属，其他无归属报告仅管理员可查阅，通过详情关联产品。包含不同产品候选的历史报告禁止直接重新归属。无归属的旧定时计划暂停，可由管理员先关联产品，再显式恢复。归档产品保留授权历史读取，阻止新业务写入和后台执行；恢复后可再次执行。已有归档计划未自动关闭 enabled，恢复产品会允许原计划继续运行。

API：GET/POST /products、PATCH /products/:id；GET/PATCH /members/:id/products（revision 防覆盖）；PATCH /research/:id/product、PATCH /schedules/:id/product 仅处理历史空归属。授权、产品创建、修改、归属修复均记录审计。产品不提供物理删除。

启动前运行 pnpm build、pnpm db:migrate。pnpm test:products 用临时产品、账号、候选、研究、任务与计划验证默认拒绝、跨产品列表/详情/SSE/写入、概览统计、成员范围、即时撤权、归档与审计，并清理数据，不调用模型。常规 pnpm test:smoke、pnpm test:workflow、pnpm test:intelligence 已改用显式测试产品授权。真实付费研究/定时脚本也携带产品，但本轮未重复付费执行。

后续竞品监控与短剧结构库应直接复用产品归属与授权、研究来源、候选审核和任务，不另建一套成员或产品目录。跨产品授权竞态的更严格事务级隔离、产品维度不同角色、归档时计划自动暂停、产品变更乐观版本及统一审计 UI 可按实际团队需求扩展。
