一 核心调整

原版主要回答“各渠道做了什么”；第二版增加“这些渠道带来的是否为纹身师、是否获得首次价值、是否付费并继续使用”。不把消费者免费试戴注册算作商户获客成功；不把一次视频生成成功直接算成真实发布。

首期优先人群假设：美国英语市场、已有真实作品照片、在社媒宣传且仍有接单空间的独立纹身师和小型工作室。首批客户需要人工陪跑确认需求，再逐步自动化成熟流程。

二 指标与数据底座

建议主指标为每周获得有效视频成果的活跃纹身师账户数：已确认从业身份，且当周至少生成并导出一条通过质量检查的视频。导出是发布意图的代理指标；真实发布另通过平台回执或用户确认记录。

商户漏斗：目标工作室 → 有效建联 → 注册 → 上传真实作品 → 视频生成成功 → 质量认可并导出 → 首次付费 → 次周复用 → 续费。

消费者漏斗：访问 → 上身预览 → 保存/分享 → 联系纹身师（未来能力）。其免费成本、留存、转商户贡献单列。产品内身份可为纹身师、店主、消费者、未知；身份由自报与人工确认记录，不由AI猜测直接定性。

四 激活与留存工作台

旅程一：注册后24小时没有合格视频导出。先判断上传失败、生成失败、效果不认可或不了解流程；分别创建技术修复、人工陪跑、模板建议任务。若已经导出，立即退出该旅程。

旅程二：首次导出后3天未复用。提供第二条真实作品制作场景；记录是否再次导出，不用打开消息作为成功。触达之前检查可联系状态、当地时区与频控。

旅程三：多次导出但未付费。根据实际使用量生成方案说明草稿；试用上限和价格须与产品实际配置一致，不能自动发放虚构优惠。

旅程四：付费工作室活跃下降。先看视频质量、生成耗时、失败与额度问题，再决定服务跟进。对于非订阅套餐，使用“复购/充值”口径，不能显示续费率。

所有旅程包括进入规则、排除规则、等待窗口、退出条件、频次上限、实验对照和负责人。初期只生成待办或草稿；正式接入后才能按已授权范围执行触达。

五 客户分群

动态分群包含未激活纹身师、高频免费视频用户、已付费活跃、付费后下降、只用试戴的消费者、未知身份用户。分群按账户计算，展示规则、人数更新时间与明细。把分群转为行动前，排除重复任务、退订、已在其他旅程和近期已触达账户。

首期线索评分采用可解释规则：从业身份、可用作品、宣传活动、产品真实行为与合作匹配度分别显示。缺失字段保持未知，AI补全必须附证据；模型评分待成交数据足够后再校准。

六 增长实验

每个实验登记假设、人群、主要指标、分流单位、最小可检测差异、所需样本、观察期、预算和护栏。工作室多人共用产品时优先账户分流，避免同一机构看到互相冲突的方案。尚未达到样本或窗口标为“证据不足”。

首批建议：视频宣传与试戴两种首屏卖点；三步视频引导；作品授权后的个性化演示；网红专业受众匹配；试用额度与付费转化。创意、受众、落地页不要同时大幅变动而声称识别了单一原因。

ICE等评分只用于排队，不能证明收益。低流量阶段先访谈与陪跑，避免开展无足够样本的多组A/B测试。对照组、固定窗口和留存观察用于减少自然增长与渠道归因的误判。

七 AI自动化运行中心

AI承担资料摘要、去重建议、情报分类、匹配解释、脚本草稿、翻译和异常分析。执行流程采用结构化规则负责触发、权限、预算、去重与状态推进，AI负责有界生成与分析。

工作流	输入与输出	人工检查点	验收

网红合作准备	公开内容与受众资料 → 简介、brief、定制草稿	确认内容依据、费用、授权	合格纹身师激活与付费，不只播放
内容生产	获授权作品 → 多钩子脚本、视频、字幕	原作品保真、画面与品牌审核	可用成片率、单条可用成本

每次运行保存输入摘要、数据版本、模型/模板版本、成本、输出、审批、错误、重试和外部回执。按工作流与业务对象设幂等键；失败重试只覆盖失败步骤，超限进入人工队列。取消审批不会产生外部动作。预算变更、发布和外发先显示具体对象与内容，不能把“审核通过”伪装成“平台已执行”。

离线评估使用已授权样例检查事实依据、图案保真、个性化准确、重复率与成本；模板或模型更新先小范围验证。关注人工节省工时、可用输出成本与实际客户效果，不以生成量或自动化百分比作为主目标。

八 产品带动增长的循环假设

作品循环：纹身师使用自己的作品 → 导出并真实发布 → 专业同行看到 → 新纹身师试用 → 新作品与反馈改善模板。需要用户授权、可追踪链接与真实发布记录。

客户沟通循环：纹身师向自己的客户展示试戴 → 获得沟通反馈 → 继续使用；是否带来新增咨询需后续证据。预约交易与消费者撮合仍是后续规划。

合作循环：专业创作者演示 → 受众纹身师注册 → 首条视频成果 → 案例回访与下一轮内容。按激活与付费衡量合作，不把所有观看者当作目标客户。

以上是本项目可测试的机制，不代表已验证的增长效果。

九 借鉴与自建取舍

研究核查于2026年11月12日至13日，以下官方能力用于结构参考，不表示已采购或接入：

- HubSpot AI平台：借鉴客户资料、营销销售与服务的共同上下文，避免各渠道重复客户记录。

- Clay与信息补全：借鉴多源补全与信号研究；本项目增加来源、匹配说明和单条成本控制。

- Customer.io旅程等待规则：借鉴行为条件和等待节点，落到激活、复用与退出逻辑。

- PostHog实验与机构分析：借鉴实验曝光、对照与账户分析，避免一个工作室多人重复计数。

- n8n人工审核：借鉴工具执行前的批准或拒绝，落到外发、预算和发布检查点。

- Google AI搜索说明：SEO基础仍然适用，新增AI发现观察而非排名承诺。

建议自建纹身行业客户模型、事件定义、成片质检、实验方法、统一工作台与行业skills；数据连接、基础CRM、消息投递和运行编排优先复用成熟工具。具体供应商采购应按实际账户规模、消息量、接入费、维护工时和迁移成本另行估价。

十 推进顺序与第二版Demo验收

第一优先：确认从业身份、视频事件与支付数据、人工陪跑、真实作品质量。第二优先：跑通一个专业网红或商户拓客渠道，再补激活复用。第三优先：在已有效的流程上加自动化、预算实验与多市场扩展。

第二版Demo保留七模块，新增四工作台；支持分群转行动、实验详情、旅程任务、模拟自动化成功与失败、运行重试与审批。全部为浏览器本地演示，无真实数据接入、定时后台运行、外部消息、广告或发布行为。正式接入状态必须可见；未接入的指标不应显示为实时结果。

以下能力与第二版闭环设计共同构成产品范围；具体落地优先级以上文推进顺序为准。

二、数据看板
2.1 总体增长看板

支持产品、国家地区、日期、渠道、活动、负责人筛选；展示访问、注册、激活、试用、付费客户、收入、广告花费、获客成本、回收与留存。核心漏斗支持逐层查看明细和流失。业务目标、实际完成、目标差距与趋势并列展示。

区分付费广告、自然社媒、SEO、网红、商务拓客和直接访问。相同客户跨渠道触达去重；无法归因的收入进入“未知来源”，不能强行分摊。首期默认展示末次非直接触点归因，同时保留首次触点供对比。收入、币种、退款、时区、去重规则随指标可查看。

2.2 渠道看板与异常

投放看花费、点击、注册、付费、CPA、ROAS；内容看发布、曝光、互动、点击、注册；SEO看曝光、点击、关键词与转化；商务看线索、回复、预约、试用、成交和周期。图表可以下钻到活动、素材和联系人，不仅停留在汇总数字。

对花费异常、转化骤降、同步失败、任务逾期设置阈值。提醒包含比较区间、受影响对象、数据更新时间及处理入口。同步延迟、空数据、失败状态明确展示，不能用零替代缺失值。

2.3 飞书数据助手

支持“昨天美国 Meta 获客成本为什么上升”“本周哪些素材值得复测”等问答。回复附时间、筛选条件、计算口径、数据来源和明细入口；信息不足时说明缺失项。可将建议转为待办，经负责人确认后执行。飞书消息接收、定时报表和卡片交互依赖实际接入能力；未接入时仅在中台生成摘要，不声称已推送。

三、信息采集
3.1 欧美热点

按美国、英国、欧洲等市场及行业标签收集热点、节日、文化事件与平台趋势，保留原链接、发布时间、语言、摘要、热度变化和适用产品。可筛选市场、来源、内容类型、时间与可信度。

3.2 竞品监控

监控指定竞品的产品变化、定价、落地页、内容、广告创意和用户评价。变化卡片展示前后差异、采集时间和证据链接。将事实、估算和分析判断分开；无法取得的数据标为未知。

3.3 欧美热门飙升短剧

记录剧名、平台、市场、题材、开场钩子、冲突结构、反转、节奏与热度趋势。可沉淀“叙事结构参考”，转成原创脚本任务；参考条目保留来源，避免把竞品整段素材直接当成自有素材。

3.4 情报转任务

每条情报可收藏、标记不相关、生成选题或建联任务，关联目标产品、渠道和负责人。重复条目合并，保留各来源。采集失败有重试记录；受来源权限限制时允许手工录入或导入。

四、投放
4.1 投放数据看板

统一 Google、Meta、TikTok 的账户、活动、广告组、广告和创意层级。保留原平台ID、币种、归因窗口、更新时间，区分平台归因与中台归因。跨平台数据只在统一口径下汇总。

4.2 素材管理

素材库支持视频、图片、文案、落地页与脚本；标签包括产品、市场、语言、卖点、钩子、画幅、演员、版本和授权。创意与投放表现关联，可比较同一创意不同版本。状态为草稿、待审、可用、投放中、停用；保留审核意见、使用记录和原文件。

4.3 Google、Meta与TikTok投放工作台

首期提供账户数据接入、投放计划、素材关联、预算建议和调整任务。创建活动、修改预算、暂停广告等平台写操作在账户授权与审核通过后逐步接入；每次执行展示对象、预算、预计影响、审批人与结果。平台不支持的动作提供可复制配置和跳转入口。

4.4 实验与复盘

每个测试记录假设、唯一主要变量、目标指标、预算上限、观察期及停止条件。结果标为胜出、继续观察或停止；样本不足不能判胜。可将高表现创意加入复用模板，并保留失败原因。

五、社媒管理
5.1 社媒看板与账号管理

统一查看各账号发布量、曝光、互动、粉丝变化、链接点击及注册。账号档案保留平台、市场、语言、定位、负责人、授权状态和账号健康。账号连接失败不能显示为正常运营。

5.2 每日内容参考

每天早上按市场、产品定位、情报与历史内容表现，生成选题、钩子、脚本大纲、形式、目标人群和行动引导。每条建议标明依据、渠道及适用原因；运营选择后转成制作任务。

5.3 视频工厂

流水线为选题、脚本、分镜、素材生成、剪辑、字幕、多语言、质检、审核、排期、发布、复盘。支持单条与批量任务；各环节可查看进度、错误、成本和重试，不因单条失败重跑全部任务。

已验证内容类型沉淀为 skills，包含适用场景、输入要求、脚本结构、视觉规范、示例和历史实验结果。模板版本与生成内容关联，便于追踪哪个方法有效。生成内容先进入待审；人工可通过、退回或修改。

5.4 发布管理

按账号、日期与市场展示日历，支持排期冲突提醒、预览、审批与失败重试。正式自动发布依赖平台权限；未接入账号用导出素材和手动发布确认。手动完成与平台回执分开标记。

六、SEO
6.1 SEO数据看板

展示自然搜索曝光、点击、点击率、关键词、排名趋势、收录情况、落地页与转化。按国家、语言、页面类型和品牌词筛选。关键词表现与产品注册、试用和付费关联。

6.2 内容参考与生产

每日结合情报、搜索需求和站内内容缺口提供关键词组、搜索意图、页面类型、文章大纲、初稿和内链建议。内容状态为选题、写作、审核、待发布、已发布、待更新；发布前检查事实、重复、品牌一致性及落地页行动引导。

6.3 内容资产与更新

页面档案关联关键词、URL、负责人、发布时间、表现与更新记录。对曝光下降、内容过时、死链、未收录建立任务。AI初稿必须经过人工判断，不以批量数量作为成功指标。

七、网红合作
7.1 发现与筛选

按平台、国家、语言、领域、粉丝区间、互动表现、受众匹配、联系方式和合作历史建立候选库。自动采集在来源允许的范围内进行，支持导入与人工补录。评分拆分受众匹配、内容质量、互动、成本与风险，不用单一粉丝数决策。

7.2 一对一定制建联

根据网红近期内容、产品适配点和合作形式生成个性化话术、brief和跟进建议。草稿必须可编辑；发送前核对联系人、平台、内容与合作条件。系统不把草稿生成当成已发送。

7.3 进度管理与归因

阶段为候选、待联系、已联系、有回复、洽谈、已签约、制作、已发布、复盘或不合作。记录报价、交付物、时间、合同、跟踪链接、优惠码、费用、播放和转化。提醒逾期交付、待跟进、待结算；同一人跨账号去重。

八、目标商户管理
8.1 目标客户与线索

按国家、城市、行业、店铺规模、网站和社媒活跃度建立商户画像。线索字段包括商户名、来源URL、联系人、联系方式、匹配理由、负责人、最近联系、下一步及拒绝联系标记。导入去重以域名、联系方式和店铺身份组合判断。

8.2 建联参考

为每家商户生成经营观察、可解决问题、产品价值点、个性化开场白与演示建议；每个观察附来源。自动化先生成草稿，人员确认后发送。拒绝联系的对象进入排除列表，不能继续进入批量队列。

8.3 销售进度与数据看板

阶段为新线索、已联系、有回复、预约演示、试用、付费、流失或不适合。看板展示各阶段数量、转化率、平均周期、来源质量与获客成本。联系人详情有沟通时间线、产品使用反馈、下一步和负责人；成交与付费记录关联而非手动虚增收入。

九、共用底座
能力	关键要求

任务状态统一为待处理、进行中、待审核、已完成、失败、已取消。失败保留原因，重试关联原任务；外部执行使用幂等标识，避免重复发消息、重复发布和重复扣费。

十、典型工作闭环

1. 情报发现美国纹身相关热点，运营生成 TikTok 选题任务。

2. 视频工厂选用已验证的内容结构，产出脚本和素材版本。

3. 负责人审核，通过后排期；接入发布能力后取得回执。

4. 投放运营把素材加入小预算测试，关联跟踪链接。

5. 看板记录点击、注册、试用与付费，识别高表现市场与卖点。

6. 商务对高意向商户跟进，记录演示和成交。

7. 复盘结果回写模板与客户画像，影响下一轮推荐。
