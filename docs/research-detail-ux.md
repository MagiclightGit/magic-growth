## 已实施

竞品详情使用独立页面内容，保留现有 competitor/batch 查询链接，支持刷新直达、浏览器历史与返回竞品监控。长报告、研究过程和个人会话不再共处大弹窗。页面顶部展示竞品身份、官网、产品、市场、频率及批次；「监控设置」作为单独短表单弹窗。

结果区按「变化概览」「完整报告」「来源与过程」导航，当前栏目保存到 view 查询参数。变化概览保留六维证据、未知标记、前后对比和核实入库操作；报告直接展开阅读；过程在正文流中展开，无额外固定高度滚动区。

详情占用工作空间导航下的可用视口，顶部压缩为身份、监控操作和批次。默认先展示研究结果，追问收起，顶部随时可打开。变化概览首先呈现六维结论摘要，点击后定位到依据；首次研究不展示空白的历史对比列。报告正文独立滚动，避免页面整体滚动将聊天输入框推到屏外。宽屏展开追问后与结果并排，聊天输入区固定在可用视口内；窄屏切换为个人追问视图，暂时收起监控配置和批次行以留出对话空间，并提供返回研究结果。报告与追问不共享滚动位置。AI Elements Conversation 管理追问消息自动跟随与回到底部，Message 管理用户/Agent 消息布局，沿用 Tool 与 Streamdown。输入框固定在聊天面板底部，Enter 发送、Shift+Enter 换行，并排除中文输入法正在组字的 Enter；空会话提供仅填入输入框的建议问题。

后台会话、产品权限、个人隔离和主动分享沿用既有实现。普通 Agent 研究详情现已统一为独立工作区，与竞品详情共享 `ResearchDetailFrame` 视口容器。研究记录保留 `?run=` 直达链接，默认展示研究报告；参考来源、执行过程和整理情报分别提供栏目，个人追问从顶部展开。研究中的 SSE 与查询回退沿用原实现，报告逐步呈现；未完成及无报告状态明确展示，不伪造摘要。长研究问题收纳到正文内的可展开说明，标题仅取原问题的开头。旧记录产品归属入口保留在整理情报栏目。

## 验证边界

使用 OiiOii 已有真实报告与个人问答检查布局，不为 UI 测试额外调用模型，不修改用户新产生的测试问答和分享记录。检查宽屏和 390px 窄屏、结果栏目、返回/重入与刷新、追问滚动、键盘换行/提交事件及分享预览。

2026-11-17 结果优先修正：实测 1456×812 宽屏、390×844 窄屏，打开追问后输入表单完整位于视口内；滚动报告到末尾不会移动输入框。构建、类型、Lint、格式及 51 项单元测试通过。

普通研究记录同步验证：使用已有 MagicTattoo 研究报告检查默认报告、112 条已保存来源、执行过程刷新定位、候选情报入口及返回后重新打开。390×844 窄屏展开追问时输入表单底部为 814px，无页面横向溢出或整体纵向滚动；竞品详情共享容器回归正常。本次未新增模型调用，未对正在执行或失败的真实研究重新发起测试。
